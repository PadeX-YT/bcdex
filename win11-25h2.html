🧹 Windows 11 25H2: Menos Bloatware, Más Control

Microsoft lo intenta de nuevo. Con la actualización de Windows 11 25H2, la compañía planea abordar una de las quejas más comunes de los usuarios: demasiadas aplicaciones preinstaladas que no se pueden eliminar fácilmente. Esta vez, habrá una forma oficial de decir adiós a aplicaciones como Media Player, Paint, Cortana o el Bloc de Notas, sin usar PowerShell ni herramientas de terceros.

⚙️ Paso 1: Abre el Editor de Políticas de Grupo

La principal novedad llega a través del Editor de Políticas de Grupo. Si usas Windows 11 Pro, simplemente presiona Win + R, escribe gpedit.msc y presiona Enter.

En el Editor de Políticas de Grupo:

  • Ve a Configuración del equipo → Plantillas administrativas → Componentes de Windows.
  • Busca la opción llamada Quitar aplicaciones preinstaladas.
  • Haz doble clic en ella.
  • Selecciona Habilitada.
  • Guarda los cambios.
  • Reinicia tu equipo. ¡Listo! Ahora puedes desinstalar aplicaciones como Paint, Media Player, Cortana, Sticky Notes, etc., directamente desde Configuración.

Si usas Windows 11 Home, el Editor de Políticas de Grupo no está disponible de forma oficial.

🔔 Notas importantes

  • No todas las aplicaciones se pueden desinstalar. Algunos componentes esenciales del sistema permanecerán protegidos.
  • Aplicaciones como Paint, Media Player, Cortana y Sticky Notes se pueden eliminar sin riesgo.
  • La disponibilidad puede variar según la compilación de Windows.
  • Siempre haz una copia de seguridad antes de modificar configuraciones críticas.

🗓️ ¿Cuándo estará disponible?

La nueva función se espera en la actualización de Windows 11 25H2. Los usuarios del programa Windows Insider ya pueden probarla en los canales de vista previa.

❓ ¿Por qué es importante?

  • Menos bloatware significa un sistema más limpio, rápido y con más espacio libre.
  • Ofrece a los usuarios más control sobre lo que permanece instalado en su PC.

🔎 Más detalles

  • Además de las aplicaciones mencionadas, otras pueden ser eliminables en el futuro a medida que Windows evolucione.
  • La lista de aplicaciones eliminables puede crecer en futuras actualizaciones.
  • Las herramientas de terceros y optimizadores aún pueden ser útiles para una eliminación avanzada.
  • Microsoft puede revertir o cambiar esta política en futuras compilaciones.

✅ Conclusión

La actualización de Windows 11 25H2 marca un paso importante en el control del usuario sobre su propio sistema operativo. Eliminar el bloatware nunca ha sido tan fácil y oficial.
